# QinTopia PMS v1.2.1

发布日期：2026-09-09。补充 QinTopia 品牌 Logo 资源和浏览器图标；Git 标签 `v1.2.1` 对应本次应用发布提交。

## 优化说明

- 使用用户提供的 QinTopia PNG Logo 作为登录页品牌标识、侧边栏品牌标识和收起侧栏后的应用图标。
- 增加浏览器 favicon 和 Apple Touch Icon，避免浏览器标签页显示空白默认图标。
- Logo 作为静态资源随 Web 生产构建发布，桌面和移动布局均保持固定比例显示。

## 升级说明

- 无数据库迁移，无新增运行时配置，不改变订单、资金、库存、会员、权限或会话行为。
- 更新 Web 容器后刷新浏览器即可看到 Logo；若浏览器仍缓存旧页面，执行一次强制刷新即可。

## 验证与已知问题

- 已通过 `npm run release:check`、`npm run typecheck`、`npm run build` 和 `git diff --check`。
- 已确认生产构建包含 `apps/web/dist/qintopia-logo.png`，`index.html` 包含 favicon 与 Apple Touch Icon 链接。
- Playwright Chromium 在当前 macOS 沙箱中无法启动，未完成自动截图；静态资源、构建输出和 HTML 引用已验证。

## 回退说明

- Logo 为纯前端静态资源，回退到 v1.2.0 即可恢复之前的文字品牌显示。
- 无需回退数据库或业务数据。
