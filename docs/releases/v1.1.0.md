上线状态：北京时间 2026-09-07 14:59 已部署，应用提交 `355ee9059e48d634bbb59380f20d4b8d9a12212c`。生产迁移 056、数据库就绪与公网健康检查通过；员工桌面及管理员手机的同住人表单、7 天登录、刷新保持登录、主动退出和 Logo 下方版本号均已验证。[GitHub Release](https://github.com/qintopia-agent-studio/GreenPMS/releases/tag/v1.1.0)

## 优化说明

- 普通员工和管理员可在已预订、在住的整房订单详情中添加同住人，解决建单漏录后无法补充的问题。普通、免费及符合房间容量的会员整房订单均支持。
- 同住人与主要入住人共用订单完整住宿日期，不单独设置个人到离日期。添加、撤销会同步纠正该订单完整期间的名册及人数，包括历史日期。
- 误录同住人可以填写原因后撤销登记，保留原资料、操作人、时间及前后名册；主要入住人不可撤销。撤销用于纠正误录，不表示个人提前退房。
- 按订单当前有效住宿安排涉及的全部房间核验容量；床位、终态及超容量订单拒绝操作。保留并发校验、重复提交保护和中断后恢复。
- 版本号以小字显示在左上角 QinTopia PMS Logo 下方，点击可查看对应版本说明。
- 补齐 `/api/v1/version` 的 OpenAPI 500 错误响应声明，使接口契约与统一错误处理一致。

## 升级说明

- 从 v1.0.0 升级需要执行数据库迁移 `056_whole_room_companions.sql`。先保留旧镜像和数据库备份，在隔离副本验证迁移及数据库就绪检查；正式切换时暂停应用写入，再迁移并启动 v1.1.0。
- 迁移增加同住人撤销事实、有效名册视图及配套保护与员工权限；不自动补录实际住宿人，不修改订单价格、资金、库存或会员权益，已有独立 API Token 的权限上限不自动扩大。
- 无需新增配置。升级完成后刷新页面即可使用；原有 7 天固定登录规则继续保留，已有会话不因本次升级重置期限。
- 操作入口为整房订单详情的入住人员区。补录人员会计入完整订单期间，请按该规则核对名单；本版不支持个人分段住宿日期。
