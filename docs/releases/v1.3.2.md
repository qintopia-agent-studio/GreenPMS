# QinTopia PMS v1.3.2

发布日期：2026-09-10。企业微信收退款生产 readiness 热修复。

## 改动说明

- 修正企业微信收退款 schema fingerprint 冻结值，使 PostgreSQL 18.4 生产迁移后的 `qintopia_runtime` 通过启动 readiness。
- 不新增数据库迁移，不改变收退款数据和匹配规则。

## 验证结果

- 生产数据库实际 fingerprint 与修正后的值一致。
- 其余 `externalPaymentsReady` 权限、角色、触发器检查已通过只读诊断。
- `npm run release:check`、TypeScript 检查和生产构建将由 PR 必需检查复核。

## 风险与回退

- 数据库已完成 v1.3.1 的 058-060 迁移；v1.3.2 只替换应用镜像，不重复迁移。
- 企业微信 Worker 继续保持关闭；如新镜像健康检查失败，恢复 v1.3.1 镜像，不回退数据库迁移。
