# QinTopia PMS v1.0.0

发布日期：2026-09-07。首个正式编号版本，在既有线上系统基础上开始统一版本管理；Git 标签 `v1.0.0` 对应本次发布提交。

上线状态：北京时间 2026-09-07 11:52 完成部署，应用提交 `f3099adf894b6036a1a2f5f1d1de3d3b288a98b5`；生产健康、版本接口、8 栋人数显示以及桌面员工/手机管理员 7 天登录、权限和主动退出验证通过。[GitHub Release](https://github.com/qintopia-agent-studio/GreenPMS/releases/tag/v1.0.0) 已正式发布。

## 优化说明

- 修复所有楼栋“今日人数”重复统计：同一住宿在父房和子床中产生不同展示记录时，仅按实际所属房间或床位计一次，普通住宿和免费住宿一致处理。总容量计算不变，不修改房间资料或住宿人员资料。
- 登录有效期从固定 12 小时调整为固定 7 x 24 小时，无 12 小时空闲退出、不随操作自动延期。主动退出、改密和会话撤销沿用原有失效规则。
- 登录页、桌面侧栏及手机顶部显示版本号；登录后的版本链接可查看 GitHub 更新说明。`GET /api/v1/version` 返回当前 API 版本，OpenAPI 同步应用版本。
- 统一采用 `v主版本.次版本.修订号`，构建时检查版本一致性及优化、升级、验证、回退说明是否齐全。

## 升级说明

- 从原线上提交 `ffc719e6ca6b7829dd8aded1c7bd85a1137a150a` 升级；本次无数据库迁移，结构保持 055，无新增环境变量，无需数据转换。
- 发布前保留旧镜像和生产备份；构建标签对应的精确提交，通过检查后替换应用容器。替换期间可能出现短暂请求失败；操作结果不明时先核对记录再重试。
- 刷新页面加载新版本。已有会话仍按原到期时间失效，主动退出并重新登录后才获得 7 天有效期；清除 Cookie 或无痕窗口关闭也会失去登录状态。
- 生产继续使用受限数据库运行身份和现有人员权限名单，禁用演示数据；不重设账号、不运行验收样例、不更改 108 录入资料。
- 分段同住人管理仍处于需求分析阶段，不包含在本次版本中。
