# QinTopia PMS v1.2.2

发布日期：2026-09-09。保留浏览器 favicon，同时撤回应用页面内的图片 Logo 展示。

- 登录页和主界面左侧导航恢复为文字品牌布局。
- 保留浏览器标签页 favicon 与 Apple Touch Icon，浏览器仍显示用户提供的 Logo。
- 清理不再使用的应用内图片 Logo 样式，避免页面增加无必要的视觉元素。

- 更新 Web 容器后刷新浏览器即可看到应用内 Logo 回退；浏览器标签页仍使用 Logo。

## 验证与已知问题

- 已确认应用源代码仅在 `index.html` 中保留 favicon 与 Apple Touch Icon 引用，登录页和主界面不再渲染图片 Logo。
