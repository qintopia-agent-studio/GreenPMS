# QinTopia PMS v1.2.3

发布日期：2026-09-09。修复房态后台刷新失败后的恢复体验，并保留写入安全门禁。

## 优化说明

- 房态查询遇到短暂网络或服务端失败时，页面会自动按 1、2、4、8 秒退避重试；浏览器回到前台时立即恢复查询。
- 自动恢复期间继续显示上次成功的房态，但不开放补录、新建住宿、换房或日期调整等写入操作。
- 将占据高度的黄色失败提示改为紧凑状态条，说明当前数据时点、自动恢复状态和写入限制；保留图标按钮供需要时立即重试。

## 升级说明

- 无数据库迁移，无新增运行时配置，不改变订单、资金、库存、会员、权限或会话数据。
- 更新 Web 容器后刷新页面即可使用自动恢复逻辑；临时失败通常无需刷新浏览器。

## 验证与已知问题

- 已通过 `npm run typecheck`、`npm test`（1,124 个测试）、`npm run build` 和 `git diff --check`。
- 已覆盖查询失败退避时间边界，并保留房态写入门禁测试。
- 自动重试只在页面可见、非权限拒绝且没有确认中的写入命令时运行；权限拒绝仍需按权限处理。

## 回退说明

- 回退到 `v1.2.2` 可恢复此前的房态失败提示和手动重试行为。
- 无需回退数据库或业务数据。
