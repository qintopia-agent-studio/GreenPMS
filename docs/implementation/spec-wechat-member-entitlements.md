# 秦托邦服务号会员权益

2026-11-19 用户确定会员端只查住宿权益，并在每份权益到期前 60 天、30 天各提醒一次。日常使用微信，首次绑定用办卡时预留的手机号接收短信验证码。涉及会员身份及跨会员数据访问，按 A 级验收。

## 首版路径

服务号菜单「我的权益」与关键词回复共用 `/member-center` 链接。会员第一次在微信里打开时，微信网页授权会给系统一个该会员在本服务号下的标识（OpenID）。会员自己验证预留手机后，系统把该标识关联到原档案。既有档案的「微信号」可以为空。一个微信在本店关联一份有效会员档案，名下多份权益自动列出。换绑先显式解除旧绑定，旧会话和订阅接收资格随之失效。

会员页只返回正式订单权益的名称、适用房型、单位、可用及预留数量、生效与截止日期、权益使用明细。按门店当地日期和购买时的订单快照计算。间夜和床夜分别显示，预订预留后入住核销只展示本次数量。不同房型共享一份额度时只列一次。消费在此指已使用的住宿权益。服务端使用专用字段白名单，财务数据、住客资料、房号和内部备注均不进入会员响应或微信提醒。

每份已生效权益按门店日历生成两个固定日期。到期日当天仍有效。窗口到来时，已绑定且允许接收、微信有适用的一次性订阅模板和当次授权的会员可以收到通知。两次提醒各需可用的微信授权，会员无需选择提前天数。启用晚于某个提醒日时从当前可用窗口开始。停机后当天可续跑，过日不补发过时提醒。按权益、有效截止日和提前天数去重，投递结果未知时保留记录供核实。日期更正按新的实际截止日计算。

## 取舍和对接

复用现有 PMS 账本、微信网页授权及一个服务号网页。发验证码使用腾讯云国内短信，Green PMS 校验后保存关联。菜单和关键词由现有账号运营方指向同一入口。微信授权和订阅能力分别配置，缺少提醒模板时仍可查询权益及两次提醒日期。

实际对接需管理员核对认证状态、网页授权域名、JS 安全域名、订阅通知类目与模板允许的字段，以及现有菜单由谁维护。AppSecret 通过服务器的安全配置提供。真实会员推送和改动线上菜单属于上线联调。[网页授权](https://developers.weixin.qq.com/doc/service/guide/h5/auth.html) · [订阅通知](https://developers.weixin.qq.com/doc/service/guide/product/subscription_messages/intro.html) · [订阅按钮](https://developers.weixin.qq.com/doc/service/guide/h5/opentag.html) · [发送接口](https://developers.weixin.qq.com/doc/service/api/notify/notify/api_sendnewsubscribemsg.html)

## 老会员第一次绑定

1. 会员用自己的微信进入「秦托邦 → 我的权益」，输入办卡时预留的中国大陆手机号，点「获取验证码」。微信基础授权自动取得本服务号的 OpenID。
2. 会员在同一页面输入短信中的 6 位数字，点「同意绑定并查看权益」。系统在同一门店核对手机号唯一对应的有效原档案，直接显示该会员的住宿权益。同一微信以后再进可直接查。
3. 一次验证码有效 5 分钟，最多核对 5 次。每个手机号及每个微信至少间隔 60 秒、各自滚动 24 小时最多申请 5 次。重新发送后使用最新的验证码。未登记、重号及其他门店的手机号均得到相同请求提示，不发送有效验证码。申请与验证时分别核对档案，期间换号或换档不会关联到新持有人。
4. 正常换微信时，先在原微信「我的权益」底部解除绑定，再用新微信验证预留手机号。原手机已停用或原微信遗失时才联系门店，按现有身份核实手续更正号码或解除原绑定。有会员建档权限的员工可在会员详情「服务号绑定」查看状态、核实后解除原绑定。员工不收集验证码。

验证码只保留带服务器密钥的摘要，绑定到本门店、当前微信会话与预留号码。验证成功、更换验证码或耗尽尝试次数后即失效。绑定使用事务及唯一约束，保留历史绑定的核验来源。验证成功后原会话失效。数据库不存短信明文，发码接口在发送前预留额度，供应商回执未知时不自动重发。

## 腾讯云短信开通与费用

1. 秦托邦运营方使用企业主体开通腾讯云短信，创建短信应用，记下短信的 `SmsSdkAppId`。在「国内短信 → 签名管理」提交主体资质和能证明关联的签名，使用审核通过的签名文字。[国内短信入门](https://cloud.tencent.com/document/product/382/37745) · [签名审核标准](https://cloud.tencent.com/document/product/382/13444)
2. 在「国内短信 → 正文模板管理」申请验证码模板。模板可提交“您正在绑定住宿会员，验证码为{1}，5分钟内有效。请勿转告他人。”首版接口只传一个参数，即验证码，5 分钟写在固定正文。实际发送使用获批模板的 ID。[SendSms 接口](https://cloud.tencent.com/document/api/382/55981)
3. 技术人员为短信应用配置专用腾讯云 CAM 凭据，授予发送所需的 `sms:SendSms` 权限。在服务器安全配置中填写 `WECHAT_MEMBER_SMS_SECRET_ID`、`WECHAT_MEMBER_SMS_SECRET_KEY`、`WECHAT_MEMBER_SMS_SDK_APP_ID`、`WECHAT_MEMBER_SMS_SIGN_NAME`、`WECHAT_MEMBER_SMS_TEMPLATE_ID`。腾讯短信应用 ID 与微信服务号 AppID 分别填写。Green PMS 在服务端签名调用 SendSms，跟踪逐条受理状态。短信配置缺失或不完整时，已绑定会员可继续查权益，新绑定入口提示尚未开通。[腾讯云 API 签名](https://cloud.tencent.com/document/api/382/52072)
4. 按腾讯云公布的中国大陆短信企业小量档，自定义套餐 1,000 条起、每条 0.05 元，起购 50 元。首次绑定通常一条，重发另占条数。日常查权益、微信到期订阅通知不消耗短信条数。正式联调时先用测试会员的微信和手机验证一条，再发布菜单。[腾讯云价格](https://cloud.tencent.com/document/api/382/8414)

## 服务号管理员设置入口

1. 在电脑上用管理员微信扫码登录，选「秦托邦」服务号，查看认证状态和现有菜单。若菜单由第三方代管，请在维护现有菜单的平台添加入口。[微信公众平台](https://mp.weixin.qq.com/)
2. 技术人员提供会员页的正式 HTTPS 网址后，打开「设置与开发 → 账号设置（或服务号设置）→ 功能设置 → 网页授权域名」。填入该网址的完整主机名。若微信要求验证，下载页面给出的校验文件，交给技术人员按提示放到相应位置，然后完成验证。[微信网页授权说明](https://developers.weixin.qq.com/doc/service/guide/h5/auth.html)
3. 在「内容与互动 → 自定义菜单」点加号，可选已有分组下的子菜单。菜单名称填「我的权益」，菜单内容选「跳转网页」，页面地址粘贴完整的会员网址，路径为 `/member-center`。先在微信中用一位测试会员走通绑定和查询，再点「保存并发布」。[微信自定义菜单说明](https://developers.weixin.qq.com/doc/service/guide/product/menu/intro.html)
4. 开通主动提醒时，在「功能设置」配置同一网站的「JS接口安全域名」，在「添加功能插件 → 订阅通知」确认所属类目是否提供合适的到期模板。会员通过微信另行授权接收提醒。[微信 JS 接口域名说明](https://developers.weixin.qq.com/doc/service/guide/h5/jssdk.html) · [订阅通知说明](https://developers.weixin.qq.com/doc/service/guide/product/subscription_messages/intro.html)

## 服务器配置与排查

1. 技术人员部署含此功能的版本，完成数据库迁移并确认会员页的公网域名。应用使用对应服务号的 AppID 与服务端密钥换取微信用户标识。
2. 服务器配置 `WECHAT_MEMBER_ENABLED=true`、`WECHAT_MEMBER_APP_ID`、`WECHAT_MEMBER_APP_SECRET`、`WECHAT_MEMBER_PROPERTY_ID`、`WECHAT_MEMBER_ORIGIN`。最后一项是页面的公网 HTTPS 源，例如 `https://member.example.com`。密钥由管理员在部署环境填入。
3. 微信后台另核对 JS 接口安全域名、适用类目、一次性订阅模板和接口 IP 白名单。确认模板实际字段后再配置 `WECHAT_MEMBER_TEMPLATE_ID` 与 `WECHAT_MEMBER_TEMPLATE_FIELDS`。例如实际模板含权益名称、到期日期、提前天数三个字段时，可映射为 `{"thing1":"product","date2":"expiry","number3":"days"}`。查询可先单独开通。使用专用域名时，只需将会员页面、它的静态资源及 `/api/wechat/member` 路由到本应用。
4. 服务进程每十分钟扫描当天到期窗口。投递记录 `wechat_member_expiry_notices` 中的 `ACCEPTED` 表示微信接口已受理，`RETRY` 为已明确退回且允许重试，`REJECTED` 为其他明确拒绝。`UNKNOWN` 为可能已提交，系统保留记录供复核。关闭开关并重启可停用会员查询和投递。

## 验收

1. 两位会员分别用登记手机和短信验证码自行绑定，转发入口只展示各自权益。同号多档、过期码、错码超限、换号、跨门店和复用旧会话均不能建立新绑定。确认同一账号重进不再发码，换绑前旧微信仍能查询。
2. 核对预订、入住、取消和更正。页面显示正式间夜或床夜明细，无任何款项。两晚预订转为入住后，可用数保持一致。
3. 合成时钟覆盖 61、60、59、31、30、29 天和到期日，检查同日重启、重复执行、未授权、解绑及日期更正。真实账号另验一次微信接收授权和实际收信。
