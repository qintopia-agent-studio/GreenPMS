# 独卫标间与大床通用会员

## 已确认决定

用户于2026-11-15明确确认：新增**一种**通用会员，售价2800元，独卫标间和独卫大床共同扣减同一份30间夜；时间、有效期、收款、生效及核销办法与其他会员一致。已授权实现、验证及提交PR；不包含合并或生产发布。

| 项目 | 规则 |
| --- | --- |
| 名称 | 独卫标间／大床通用会员 |
| 默认价 | 2800元（280000分）；偏离标价的成交价继续要求调价原因 |
| 适用房型 | `private_bath_standard`、`private_bath_king`，销售单位均为整房 |
| 权益 | 一份合同、一份30 `ROOM_NIGHT` Lot；两房型合计30间夜 |
| 有效期 | 正常办理以门店当地日期显式生效，截止日沿用一个日历年算法；管理员历史补录及日期更正沿用原授权条件 |
| 核销 | 每间房每晚1间夜；预订冻结、入住核销、未入住取消释放，已核销处理遵循对应生命周期 |
| 房型切换 | 两适用房型均为正常匹配；换房不新增权益，不重置有效期，不要求临时安排原因 |

本规格是对第2步[会员订单](spec-step-2b-membership-orders.md)和[会员住宿](spec-step-2c-member-balances-and-stays.md)中“三种固定产品/单一适用房型”约束的已确认增量，其余规则继续有效。不是重新定义所有会员的资金或生命周期。

历史2026参考价格目录是已封存的来源事实，保留其原始三产品记录，不将新产品伪装成原表已发布内容。当前在售产品从正式会员产品目录读取。

## 业务路径

- 办理、收款、生效：沿用原命令及权限；零有效收款不可生效；收款差额仍核对展示，不自动调价或推断结清。
- 报价、建单、续住、换房：按目标房型是否属于该份快照集合匹配；标间5晚加大床3晚只使用8间夜、余22。保留库存、账本与幂等事务约束。
- 余额不足、过期、重叠权益：仍按现有部分/零覆盖和多Lot歧义处理；不因新增产品自行选择权益消耗顺序。
- 在住升级：整段住宿只有上述两房型时属于普通匹配；涉及范围之外的整房仍按[临时升级规格](../../待开发项/spec-cross-room-membership-upgrade.md)核对现场原因及连续房间时间线。
- 临时安排其他整房：保留现有例外、全晚覆盖及唯一来源要求；不得将产品正常范围内房型误判为临时安排，也不将旧临时例外扩大成永久适用。
- 管理员补录、纠错、作废重建、房源管理：沿用权限和不可变事实；新会员快照能完整传递，现存会员与房源保护正确识别集合。
- 普通会员入住后的缩短与在住升级后的缩短，继续各自既有已确认规则；本次不把释放冻结等同退会员费。
