# 普通住宿本单金额角分修复

2026-10-15用户生产截图：WECOM来源的历史住宿补录，本单金额387.5、实收387.5，选中真实企微流水后被“本单金额格式不正确，请填写非负整数金额”挡住。

## 最新决定与范围

截图明确要求普通住宿真实本单金额可录入角分。本次覆盖此前“仅外部渠道支持角分、直订仍整元”的限制：普通WECOM住宿手工本单金额最多两位小数，金额以整数分存储；补录、新建及后续更正/改期/续住/缩短/换房保持一致。政策基础价原有整元舍入不变；会员卡约定价格、会员住宿及免费住宿规则不放开。已有人工调价原因、权限、日期、事务与金额上限保持。

实际企微收款与手工本单金额是不同字段；前者原已支持分，不能因此声称后者已经支持。增加073迁移，仅扩展普通WECOM的金额精度条件，不编辑旧迁移或CI。

## 验收标准

- 补录WECOM本单387.5及实收387.5，选中成功流水并填写既有必要原因后，预览和正式回执均为38750分；不通过取整、改渠道或抬高合同绕过。
- 387.50、0.01及上限边界按规则支持；三位小数、负数、分以下值及溢出拒绝。实际收款不得超过本单金额。
- 普通订单各后续变更保留手工最终金额精度；政策价计算、会员金额和免费零价等原规则不变。
- 正式迁移/Preview/Confirm/订单读回在全新隔离库验证；人工验收与生产上线单独记录。
