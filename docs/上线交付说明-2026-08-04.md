## API 接入方式

### 认证

外部客户端使用 Bearer Token：

```
Authorization: Bearer <token-secret>
```

Token 只显示一次，服务端只存 SHA-256 哈希。

### 必要请求头

所有写操作（POST）必须携带：

```
Idempotency-Key: <唯一键>
X-Correlation-ID: <关联ID>
```

### 报价接口

```
POST /api/v1/quotes
```

返回的 `quote.currentContractAmount` 是最终应收金额。`cashLines[].amount` 是明细行金额。不再返回内部计算字段（`numeratorMinor` 等），外部客户端不需要也不会看到中间计算过程。

### 订单创建

订单创建使用两阶段 Preview/Confirm：

1. `POST /api/v1/command-previews` — 生成预览
2. `POST /api/v1/command-previews/:id/confirm` — 确认执行

中断恢复使用 `POST /api/v1/command-results/resolve`，携带原始幂等键查询最终状态。

## 启动和停止

### 本地开发

```bash
# 启动数据库
docker compose up -d postgres

# 启动 API（端口 4146）
PORT=4146 WEB_ORIGIN=http://127.0.0.1:4196 \
  DATABASE_URL=postgres://qintopia:qintopia@127.0.0.1:55432/qintopia_e2e \
  TSX_DISABLE_IPC=1 node --import tsx apps/api/src/main.ts

# 启动前端（端口 4196）
WEB_PORT=4196 API_PROXY_TARGET=http://127.0.0.1:4146 \
  npx vite --host 127.0.0.1 --port 4196
```

### 生产部署

```bash
cp .env.example .env
# 编辑 .env，填入真实 DATABASE_URL、WEB_ORIGIN 等
docker compose -f compose.server.yaml up --build -d
```

### 停止

```bash
docker compose -f compose.server.yaml down
```
